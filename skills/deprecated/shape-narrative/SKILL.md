# shape-narrative (retired)

This skill was merged into [`write-finding`](../../write-finding/SKILL.md). Writing a finding and shaping its narrative were one step that no reader saw as two.

- The portable procedure moved to `write-finding`: answer first, one claim per section, the reader's words, and the check that a reworded claim still means what its source meant.
- The narrative criteria moved to `skills/write-finding/references/narrative-criteria.md`. The portable path now reaches them. The analysis-review Reader lens reads the same file.
- The Engine procedure moved to `skills/write-finding/references/engine-narrative.md`. It is still the `shape_narrative` stage of an Engine run.

This directory sits in the `deprecated` bucket, so the plugin and the package index do not ship it.
