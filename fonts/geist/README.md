# Geist (vendored)

`Geist-Variable.ttf` is the variable-weight Geist Sans from https://github.com/vercel/geist-font at commit
`10dc7658f13c38a474cde201bb09a4617267545b`, unmodified. Licence: SIL Open Font License 1.1 (`OFL.txt`).

The renderer embeds it into a Finding's HTML when an Instance sets `render.font.preset: geist` in
`aftergrid.yaml`, and hands it to the PNG rasterizer. See `docs/contracts/render.md`, "Fonts".
