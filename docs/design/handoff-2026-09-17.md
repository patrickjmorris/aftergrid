## How the work was done

Implementation in git worktrees by Opus agents (one bead each), then an adversarial review agent (two lenses,
refute-your-own-findings), a fix agent with fail-before/pass-after tests, and for larger changes an independent
re-verification against the reviewer's repros. Merge to `main`, full suite, push, CI watch, close the bead with a
comment naming the commits. Bounded reviews by CobaltSpring (codex) via agent mail on request.

Headless `/analyze` runs: from the Instance root, `claude --plugin-dir <copy of the plugin OUTSIDE the repo>
--permission-mode acceptEdits --allowedTools "Bash(aftergrid:*)" … -p "/analyze …"`, with `analytics/golden/`
moved out of the Instance for the duration (it is the answer key) and restored after. Loading the plugin from the
repo itself makes every write inside the repo "a sensitive file" (Claude Code protects the loaded plugin's tree).
The CLI is on PATH through a one-line shim to `bin/aftergrid.mjs`. All runs used the owner's Max subscription;
the `total_cost_usd` in the JSON envelope is an estimate at API list price, not a charge.
