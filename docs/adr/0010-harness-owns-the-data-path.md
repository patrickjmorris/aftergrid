# The harness owns the data path; the Engine records what it ran

Operators already work in an agent harness with its own data access: Claude Code, Cursor, Codex and ChatGPT Work with MCP servers or CLIs, Devin's Data Analyst with MCP-only marketplace connectors. Every one of those harnesses has a shell, so the CLI of ADR 0005 stays; what changes is who executes SQL. The default path is **recorded**: the agent runs queries and Checks through whatever tool the harness gives it, `aftergrid record` saves the SQL, parameters, result and their hashes into the Finding, and the Finding is labelled `artifact_replay` only. An adapter (DuckDB for fixtures and CI, Postgres because the first Instance is Postgres) is an **upgrade** that the same Finding gains when an Instance configures one: retained inputs, mechanical Check outcomes, `check --mode rerun` and Revisit (ADR 0009). No further connectors are built; a warehouse the Operator can reach from the harness is reachable enough. The evidence: Devin's DANA connects to data through MCP alone; DoorDash's Vera found the harness's catalog and SQL validation, not the model, drove accuracy (Claude Code with the same skills scored 48% to Vera's 73%), and that catalog lives with whoever owns the data path; Spotify's Confidence ships one skill set across four harnesses by calling a remote MCP for its control plane and never touching the warehouse from the agent. Building connectors would compete on exactly the layer those systems own and the Engine cannot. The cost is real and stated on every Finding: on the recorded path, Checks-before-SQL are reported by the agent rather than executed by the CLI, so the guardrail hook (ADR 0006) covers only shell commands in Claude Code and its non-coverage travels with the verdict, and a Finding cannot be rerun or revisited until retained inputs exist. Skills document the recorded path first; the adapter path is the exception they mention, not the world they assume. Revisit if Readers or Operators keep asking to rerun a recorded Finding, which is the signal to unfreeze the adapter layer rather than to write connectors.
